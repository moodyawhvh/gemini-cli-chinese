# Gemini CLI 认证设置

要使用 Gemini CLI,你需要通过 Google 完成认证。本指南帮助你根据自己的账号类型和
使用方式,快速找到最合适的登录方式。

> [!TIP]
> 想要所有可用订阅的高层次对比?请访问我们的
> [套餐页面](https://geminicli.com/plans/),比较各方案的功能与配额。

对大多数用户,我们建议直接启动 Gemini CLI 并使用个人 Google 账号登录。

## 选择你的认证方式 <a id="auth-methods"></a>

在下表中选择与你情况相符的认证方式:

| 用户类型 / 场景                                                         | 推荐的认证方式                                                     | 是否需要 Google Cloud 项目                                  |
| :--------------------------------------------------------------------- | :--------------------------------------------------------------- | :---------------------------------------------------------- |
| 个人 Google 账号                                                       | [Sign in with Google](#login-google)                             | 否(有例外)                                                |
| 使用公司、学校或 Google Workspace 账号的组织用户                       | [Sign in with Google](#login-google)                             | [是](#set-gcp)                                              |
| 持有 Gemini API key 的 AI Studio 用户                                  | [使用 Gemini API Key](#gemini-api)                               | 否                                                          |
| Google Cloud Vertex AI 用户                                            | [Vertex AI](#vertex-ai)                                          | [是](#set-gcp)                                              |
| [无头模式](#headless)                                                  | [使用 Gemini API Key](#gemini-api) 或<br /> [Vertex AI](#vertex-ai) | 否(Gemini API Key)<br /> [是](#set-gcp)(Vertex AI)      |

### 我的 Google 账号是什么类型?

- **个人 Google 账号:** 包括所有
  [免费层级账号](../resources/quota-and-pricing.md#free-usage)(例如个人版
  Gemini Code Assist),以及
  [Google AI Pro 和 Ultra](https://gemini.google/subscriptions/) 付费订阅。

- **组织账号:** 通过公司、学校或
  [Google Workspace](https://workspace.google.com/) 等组织使用付费许可的账号,
  包括 [Google AI Ultra for Business](https://support.google.com/a/answer/16345165)
  订阅。

## (推荐)使用 Google 账号登录 <a id="login-google"></a>

如果你在本地机器上运行 Gemini CLI,最简单的认证方式就是用 Google 账号登录。
这种方式要求某台机器上有网页浏览器,并且该机器能与运行 Gemini CLI 的终端通信
(例如你的本地机器)。

如果你是 **Google AI Pro** 或 **Google AI Ultra** 订阅用户,请使用与订阅关联的
Google 账号。

认证并使用 Gemini CLI:

1. 启动 CLI:

   ```bash
   gemini
   ```

2. 选择 **Sign in with Google**。Gemini CLI 会通过你的网页浏览器打开登录提示,
   按屏幕指引操作即可。凭据会被缓存在本地,供以后的会话使用。

### 我需要设置 Google Cloud 项目吗?

大多数个人 Google 账号(免费和付费)认证时都不需要 Google Cloud 项目。
但只要满足以下任一条件,就需要设置:

- 你使用的是公司、学校或 Google Workspace 账号。
- 你使用的是来自 Google Developer Program 的 Gemini Code Assist 许可。
- 你使用的是 Gemini Code Assist 订阅附带的许可。

操作步骤见[设置你的 Google Cloud 项目](#set-gcp)。

## 使用 Gemini API key <a id="gemini-api"></a>

如果不想通过 Google 账号认证,可以使用来自 Google AI Studio 的 API key。

使用 Gemini API key 认证并运行 Gemini CLI:

1. 从 [Google AI Studio](https://aistudio.google.com/app/apikey) 获取你的
   API key。

2. 将 `GEMINI_API_KEY` 环境变量设置为你的 key。例如:

   <Tabs>
     <TabItem label="macOS/Linux">

     ```bash
      # Replace YOUR_GEMINI_API_KEY with the key from AI Studio
      export GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
     ```

     </TabItem>
     <TabItem label="Windows (PowerShell)">

     ```powershell
      # Replace YOUR_GEMINI_API_KEY with the key from AI Studio
      $env:GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
     ```

     </TabItem>
   </Tabs>

   要让该设置持久生效,见[持久化环境变量](#persisting-vars)。

3. 启动 CLI:

   ```bash
   gemini
   ```

4. 选择 **Use Gemini API key**。

> [!WARNING]
> 请把 API key(尤其是 Gemini 这类服务的 key)当作敏感凭据对待。
> 妥善保管,防止未授权访问以及你的账号被滥用。

## 使用 Vertex AI <a id="vertex-ai"></a>

要在 Google Cloud 的 Vertex AI 平台上使用 Gemini CLI,可从以下认证方式中选择:

- A. 通过 `gcloud` 使用应用默认凭据(ADC)。
- B. 服务账号 JSON 密钥。
- C. Google Cloud API key。

无论选择哪种 Vertex AI 认证方式,你都需要把 `GOOGLE_CLOUD_PROJECT` 设置为启用了
Vertex AI API 的 Google Cloud 项目 ID,并把 `GOOGLE_CLOUD_LOCATION` 设置为
[Vertex AI 资源所在地区](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/locations)
或你希望运行任务的位置。

例如:

<Tabs>
  <TabItem label="macOS/Linux">

  ```bash
# Replace with your project ID and desired location (for example, us-central1)
export GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID"
export GOOGLE_CLOUD_LOCATION="YOUR_PROJECT_LOCATION"
  ```

  </TabItem>
  <TabItem label="Windows (PowerShell)">

  ```powershell
# Replace with your project ID and desired location (for example, us-central1)
$env:GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID"
$env:GOOGLE_CLOUD_LOCATION="YOUR_PROJECT_LOCATION"
  ```

  </TabItem>
</Tabs>

要让 Vertex AI 相关环境变量持久生效,见[持久化环境变量](#persisting-vars)。

#### A. Vertex AI - 通过 `gcloud` 使用应用默认凭据(ADC)

如果你已安装 Google Cloud CLI,推荐考虑这种认证方式。

如果之前设置过 `GOOGLE_API_KEY` 或 `GEMINI_API_KEY`,使用 ADC 前必须先取消:

<Tabs>
  <TabItem label="macOS/Linux">

  ```bash
unset GOOGLE_API_KEY GEMINI_API_KEY
  ```

  </TabItem>
  <TabItem label="Windows (PowerShell)">

  ```powershell
Remove-Item Env:\GOOGLE_API_KEY, Env:\GEMINI_API_KEY -ErrorAction Ignore
  ```

  </TabItem>
</Tabs>

1. 确认你拥有 Google Cloud 项目且 Vertex AI API 已启用。

2. 登录 Google Cloud:

   ```bash
   gcloud auth application-default login
   ```

3. [配置你的 Google Cloud 项目](#set-gcp)。

4. 启动 CLI:

   ```bash
   gemini
   ```

5. 选择 **Vertex AI**。

#### B. Vertex AI - 服务账号 JSON 密钥

在非交互环境、CI/CD 流水线中,或当你的组织限制基于用户的 ADC 或 API key 创建时,
可考虑这种认证方式。

如果之前设置过 `GOOGLE_API_KEY` 或 `GEMINI_API_KEY`,必须先取消:

<Tabs>
  <TabItem label="macOS/Linux">

  ```bash
unset GOOGLE_API_KEY GEMINI_API_KEY
  ```

  </TabItem>
  <TabItem label="Windows (PowerShell)">

  ```powershell
Remove-Item Env:\GOOGLE_API_KEY, Env:\GEMINI_API_KEY -ErrorAction Ignore
  ```

  </TabItem>
</Tabs>

1.  [创建服务账号和密钥](https://cloud.google.com/iam/docs/keys-create-delete),
    下载生成的 JSON 文件,并为服务账号分配 "Vertex AI User" 角色。

2.  将 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量设置为该 JSON 文件的绝对路径。
    例如:

    <Tabs>
      <TabItem label="macOS/Linux">

      ```bash
        # Replace /path/to/your/keyfile.json with the actual path
        export GOOGLE_APPLICATION_CREDENTIALS="/path/to/your/keyfile.json"
      ```

      </TabItem>
      <TabItem label="Windows (PowerShell)">

      ```powershell
        # Replace C:\path\to\your\keyfile.json with the actual path
        $env:GOOGLE_APPLICATION_CREDENTIALS="C:\path\to\your\keyfile.json"
      ```

      </TabItem>
    </Tabs>

3.  [配置你的 Google Cloud 项目](#set-gcp)。

4.  启动 CLI:

    ```bash
    gemini
    ```

5.  选择 **Vertex AI**。

> [!WARNING]
> 请妥善保管你的服务账号密钥文件——它可以访问你的云资源。

#### C. Vertex AI - Google Cloud API key

1.  获取 Google Cloud API key:
    [获取 API Key](https://cloud.google.com/vertex-ai/generative-ai/docs/start/api-keys?usertype=newuser)。

2.  设置 `GOOGLE_API_KEY` 环境变量:

    <Tabs>
      <TabItem label="macOS/Linux">

      ```bash
        # Replace YOUR_GOOGLE_API_KEY with your Vertex AI API key
        export GOOGLE_API_KEY="YOUR_GOOGLE_API_KEY"
      ```

      </TabItem>
      <TabItem label="Windows (PowerShell)">

      ```powershell
        # Replace YOUR_GOOGLE_API_KEY with your Vertex AI API key
        $env:GOOGLE_API_KEY="YOUR_GOOGLE_API_KEY"
      ```

      </TabItem>
    </Tabs>

    如果看到类似 `"API keys are not supported by this API..."` 的报错,
    说明你的组织可能限制该服务使用 API key。请改用其他 Vertex AI 认证方式。

3.  [配置你的 Google Cloud 项目](#set-gcp)。

4.  启动 CLI:

    ```bash
    gemini
    ```

5.  选择 **Vertex AI**。

## 设置你的 Google Cloud 项目 <a id="set-gcp"></a>

> [!IMPORTANT]
> 大多数个人 Google 账号(免费和付费)认证时不需要 Google Cloud 项目。

使用 Google 账号登录时,有时需要为 Gemini CLI 配置一个 Google Cloud 项目。
满足以下任一条件时适用:

- 你使用的是公司、学校或 Google Workspace 账号。
- 你使用的是来自 Google Developer Program 的 Gemini Code Assist 许可。
- 你使用的是 Gemini Code Assist 订阅附带的许可。

配置 Gemini CLI 使用 Google Cloud 项目:

1.  [查找你的 Google Cloud 项目 ID](https://support.google.com/googleapi/answer/7014113)。

2.  [启用 Gemini for Cloud API](https://cloud.google.com/gemini/docs/discover/set-up-gemini#enable-api)。

3.  [配置必要的 IAM 访问权限](https://cloud.google.com/gemini/docs/discover/set-up-gemini#grant-iam)。

4.  配置环境变量:将 `GOOGLE_CLOUD_PROJECT` 或 `GOOGLE_CLOUD_PROJECT_ID`
    设置为要配合 Gemini CLI 使用的项目 ID。Gemini CLI 会优先检查
    `GOOGLE_CLOUD_PROJECT`,然后回退到 `GOOGLE_CLOUD_PROJECT_ID`。

    例如,设置 `GOOGLE_CLOUD_PROJECT_ID` 变量:

    <Tabs>
      <TabItem label="macOS/Linux">

      ```bash
        # Replace YOUR_PROJECT_ID with your actual Google Cloud project ID
        export GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID"
      ```

      </TabItem>
      <TabItem label="Windows (PowerShell)">

      ```powershell
        # Replace YOUR_PROJECT_ID with your actual Google Cloud project ID
        $env:GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID"
      ```

      </TabItem>
    </Tabs>

    要让该设置持久生效,见[持久化环境变量](#persisting-vars)。

## 持久化环境变量 <a id="persisting-vars"></a>

为避免每次打开终端都要重新设置环境变量,可以采用以下方式持久化:

1.  **把环境变量写入 shell 配置文件:** 将环境变量命令追加到 shell 的启动文件中。

    <Tabs>
      <TabItem label="macOS/Linux">

      (例如 `~/.bashrc`、`~/.zshrc` 或 `~/.profile`):

      ```bash
        echo 'export GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID"' >> ~/.bashrc
        source ~/.bashrc
      ```

      </TabItem>
      <TabItem label="Windows (PowerShell)">

      (例如 `$PROFILE`):

      ```powershell
        Add-Content -Path $PROFILE -Value '$env:GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID"'
        . $PROFILE
      ```

      </TabItem>
    </Tabs>

> [!WARNING]
> 注意:在 shell 配置文件中导出 API key 或服务账号路径后,
> 由该 shell 启动的任何进程都能读到它们。

2.  **使用 `.env` 文件:** 在项目目录或主目录下创建 `.gemini/.env` 文件。
    Gemini CLI 会自动加载它找到的第一个 `.env` 文件:从当前目录逐级向上搜索,
    然后查找主目录的 `.gemini/.env`(例如 `~/.gemini/.env` 或
    `%USERPROFILE%\.gemini\.env`)。

    用户级配置示例:

    <Tabs>
      <TabItem label="macOS/Linux">

      ```bash
        mkdir -p ~/.gemini
        cat >> ~/.gemini/.env <<'EOF'
        GOOGLE_CLOUD_PROJECT="your-project-id"
        # Add other variables like GEMINI_API_KEY as needed
        EOF
      ```

      </TabItem>
      <TabItem label="Windows (PowerShell)">

      ```powershell
        New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.gemini"
        @"
        GOOGLE_CLOUD_PROJECT="your-project-id"
        # Add other variables like GEMINI_API_KEY as needed
        "@ | Out-File -FilePath "$env:USERPROFILE\.gemini\.env" -Encoding utf8 -Append
      ```

      </TabItem>
    </Tabs>

变量只会从找到的第一个文件加载,不会合并多个文件。

## 在 Google Cloud 环境中运行 <a id="cloud-env"></a>

在某些 Google Cloud 环境中运行 Gemini CLI 时,认证是自动完成的。

在 Google Cloud Shell 环境中,Gemini CLI 通常会用你的 Cloud Shell 凭据自动完成
认证。在 Compute Engine 环境中,Gemini CLI 会自动使用来自环境元数据服务器的
应用默认凭据(ADC)。

如果自动认证失败,请使用本页介绍的交互式认证方式之一。

## 无头模式运行 <a id="headless"></a>

[无头模式](../cli/headless.md)会复用你现有的认证方式(如果已有缓存的认证凭据)。

如果尚未用任何凭据登录过,则必须通过环境变量配置认证:

- [使用 Gemini API Key](#gemini-api)
- [Vertex AI](#vertex-ai)
