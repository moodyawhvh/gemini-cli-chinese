## 📖 项目简介

Gemini CLI 是 Google 官方开源的命令行 AI 智能体,把 Gemini 大模型的能力直接带到终端。它提供对 Gemini 最轻量的访问路径——从你的提示词直达模型,内置 Google 搜索接地、文件操作、Shell 命令、网页抓取等工具,并支持 MCP 协议扩展。个人 Google 账号即可享受免费额度:每分钟 60 次请求、每天 1000 次。

## ✨ 主要特性

- 🎯 **免费额度**:个人 Google 账号每分钟 60 次、每天 1000 次请求
- 🧠 **Gemini 3 模型**:更强的推理能力与 100 万 token 上下文窗口
- 🔧 **内置工具**:Google 搜索接地、文件操作、Shell 命令、网页抓取
- 🔌 **可扩展**:支持 MCP(Model Context Protocol)自定义集成
- 💻 **终端优先**:为命令行重度用户设计
- 🛡️ **开源**:Apache 2.0 许可证

## 🚀 快速开始

完整源代码请访问原项目:https://github.com/google-gemini/gemini-cli

1. 无安装直接运行(npx):

```bash
npx @google/gemini-cli
```

2. 或全局安装(npm):

```bash
npm install -g @google/gemini-cli
```

3. 或 Homebrew(macOS/Linux):

```bash
brew install gemini-cli
```

4. 首次运行使用个人 Google 账号登录,即可使用免费额度
5. 在终端输入提示词开始对话,试试让它读代码、改文件、跑命令
